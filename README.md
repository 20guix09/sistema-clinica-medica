# MediAgenda – Sistema de Gestão para Clínica Médica

O **MediAgenda** é um sistema web desenvolvido para facilitar o gerenciamento de clínicas médicas, consultórios e centros de atendimento. Seu principal objetivo é centralizar todas as informações da clínica em uma única plataforma, tornando a administração mais organizada, segura e eficiente.

A aplicação permite que recepcionistas e administradores realizem o cadastro de pacientes, médicos e especialidades, além de agendar, editar, consultar e cancelar consultas de forma rápida e intuitiva. Com uma interface moderna e responsiva, o sistema reduz o uso de controles manuais e minimiza erros na organização dos atendimentos.

O sistema conta com autenticação de usuários por meio de login seguro com JWT, garantindo que apenas pessoas autorizadas tenham acesso às informações da clínica. Todos os dados são armazenados em um banco de dados, permitindo consultas rápidas e gerenciamento eficiente dos registros.

Como diferencial, o sistema utiliza uma API externa para preenchimento automático de endereços por CEP, agilizando o cadastro de pacientes e reduzindo erros de digitação.

### Principais funcionalidades

* Login seguro com autenticação JWT.
* Cadastro, edição, listagem e exclusão de pacientes.
* Cadastro e gerenciamento de médicos.
* Cadastro de especialidades médicas.
* Agendamento, edição, consulta e cancelamento de consultas.
* Dashboard com indicadores da clínica.
* Pesquisa e filtros para facilitar a localização de registros.
* Interface responsiva para computadores, tablets e smartphones.

### Objetivo

O MediAgenda busca oferecer uma solução prática para clínicas médicas que desejam digitalizar seus processos administrativos, proporcionando maior organização, produtividade e qualidade no atendimento aos pacientes. O projeto foi desenvolvido seguindo conceitos modernos de desenvolvimento web, utilizando arquitetura de backend, banco de dados relacional, APIs REST, autenticação segura e uma interface amigável, podendo futuramente ser expandido com funcionalidades como prontuário eletrônico, notificações, pagamentos online, relatórios e integração com outros sistemas de saúde.
